Ingest — pull the clip's audio
Browsers can't do this: TikTok/IG send no CORS headers, so a page alone can't fetch the audio. The engine must.

TikTok unofficial

Embed page via curl_cffi (real-browser TLS) to get the play URL. Falls back to tikwm, item API, oEmbed.

Instagram unofficial

Reel embed via curl_cffi. No login — the TLS fingerprint is the whole trick. Long ?igsh= links resolve as private.

3
The engine — server.py on 127.0.0.1:8788, serves the app AND the API on one origin
This is the whole product. It runs as a small local server on the Mac.

1. Name the song Shazam

find_song.py — Shazam fingerprint (shazamio, keyless, unofficial). Phase 1 scans the whole clip for distinct songs. Phase 2 counter-speed sweep undoes slowed / sped edits Shazam won't match straight. This sweep is the moat.

2. Find the exact edit works

crate_engine.py — search SoundCloud + YouTube (yt-dlp), download each candidate, rank by chromaprint overlap (verify.py, fpcalc). Audio decides, not titles.

3. Fallbacks works

Read the uploader's caption and comments on both platforms; mine the TikTok sound page. Splits mashups and names each part with timestamps.

▼ the engine calls out to these while it works
4
Outside services it talks to
All third-party. Each is a cost or a limit at scale.

Shazam unofficial

shazamio, keyless, Apple owns Shazam. Rate-limits on concurrency. Launch needs migration to ShazamKit (bridge built, needs Apple Developer account).

SoundCloud + YouTube search

Used to hunt the edit. SoundCloud save is blocked — needs a client_id behind an Artist Pro subscription. Konnor's #1 differentiator.

Links out works

Apple Music + Deezer for the base song, a link per edit. Link out only, no in-app playback.

Spotify 5-user cap

Auto-playlist "Found with Addify". Dev mode caps at 5 users until the company is incorporated.

▼ result goes back out to the phone
5
Delivery — Mac to phone
This is the biggest launch gap: it's one Mac behind a tunnel, not a hosted backend.

Tunnel one Mac

cloudflared exposes the local engine as a public link, kept alive by a watchdog. If the Mac sleeps, the app is down.

The app UI works

crate.html — the whole interface, loaded from the engine. A UI change is live instantly, no rebuild.

Native iOS app not built

ios/ — app + share extension committed but never compiled (no Xcode on the Mac). Reaches phones only through a TestFlight build.

Backend and usage limits, plainly: unofficial Shazam and scraping (fine for a personal tool, not a licensed foundation at scale) · single Mac + tunnel, no hosted backend · Spotify capped at 5 users · SoundCloud save blocked on API access · native iOS app not yet compiled · 5-7% of clips are un-IDable without a paid recognition API.
